# Erscheinungsbild

Das Erscheinungsbild der **öffentlichen Website**: Theme, Logo und Symbol. Die Verwaltung behält immer ihr eigenes.

## Ein Theme wählen

Jedes Theme wird mit seinen drei Farben (Hintergrund, Tinte, Akzent) und einer Beschreibung vorgestellt.

1. Klicken Sie unter einem Theme auf **Vorschau**: Die Website öffnet sich in einem neuen Tab mit diesem Theme.
   - **Nur Sie** sehen es.
   - Ein Banner oben auf der Seite erinnert daran.
   - Die Vorschau folgt Ihrem Surfen eine Stunde lang oder bis **Quitter l’aperçu** (Vorschau beenden).
2. Um es für alle Besucher anzuwenden: Wählen Sie das Theme aus und klicken Sie auf **Erscheinungsbild speichern**.

| Theme | Charakter |
|---|---|
| **Atelier** | warmes Papier, kursive Überschriften |
| **Nicephos — Nacht** | schwarze Galerie, weiße Linie, gesperrte Großbuchstaben, Sandakzent |
| **Nicephos — Tag** | dieselbe Identität auf weißem Hintergrund |

## Marke

- **Nur der Name der Website** oder **Emblem + Name (+ Untertitel)**. Die zweite Wahl ist nur möglich, wenn ein Emblem oder ein Symbol hochgeladen wurde.
- **Untertitel**: zum Beispiel „Photography gallery“, höchstens 60 Zeichen.
- Der **Name** der Website wird unter [Öffentliche Website](reglages#site-public) eingestellt.

## Logos: vier Plätze

| Platz | Was hochladen | Wo es erscheint |
|---|---|---|
| **Emblem (Grafik)** | nur die Grafik, ohne Text | Kopfzeile, neben dem Namen, am Computer |
| **Symbol (vereinfachte Version)** | Version mit dicker Linie, idealerweise ein Quadrat von 512 px | Browser-Tab, Startbildschirm des Smartphones, Kopfzeile auf dem Smartphone |
| **Vollständiges Logo** | das Logo mit dem Namen (horizontale Version) | groß, oben auf der Seite „Über uns“ |
| **Teilen-Bild** | Quadrat von 1080 px oder 1200 × 630 | Vorschau, wenn eine Seite ohne Foto in einem sozialen Netzwerk geteilt wird |

- **Hochladen:** Wählen Sie die Datei (PNG, WebP oder JPEG, höchstens 5 MB) und dann **Senden**. **Ersetzen** funktioniert genauso; die alte Datei wird gelöscht.
- **Entfernen:** eine Schaltfläche unter jedem Platz.
- **Automatische Farbe:** Emblem, Symbol und vollständiges Logo übernehmen **die Farbe des Themes** (weiß auf schwarzem Hintergrund, schwarz auf hellem Hintergrund). Eine einzige Version genügt, schwarz oder weiß: Die Richtung der Linie wird erkannt. Der Rand wird automatisch beschnitten.
- **Tab-Symbol:** Ein quadratisches Symbol auf deckendem Hintergrund wird unverändert übernommen. Andernfalls wird es automatisch zusammengesetzt.
- **Foto einer Zeichnung:** Die Ausrichtung des Telefons wird angewendet; eine fotografierte Zeichnung erscheint nicht verdreht.
- **Teilen-Bild:** als JPEG neu kodiert, höchstens 1200 px. Transparenz wird hinter einer dunklen Zeichnung (freigestelltes schwarzes Logo) zu **weißem**, hinter einer hellen zu **schwarzem** Hintergrund.
- **SVG:** beim Hochladen abgelehnt.
