# Gesten und Tastenkürzel

## In der Verwaltung

| Wo | Geste | Wirkung |
|---|---|---|
| Überall | **⌘K** (Strg+K) | Palette: ein Foto, eine Serie, eine Seite suchen oder eine Aktion starten |
| Überall | **Tab** gleich beim Aufruf | zeigt **Zum Inhalt springen**: Eingabe überspringt die Seitenleiste |
| Überall | Schaltfläche **Sonne / Mond** | heller oder dunkler Modus |
| Fotothek | **Klick** auf ein Vorschaubild | wählt nur dieses aus: der Inspektor zeigt es |
| Fotothek | **Umschalt + Klick** · **⌘ + Klick** · **⌘A** · **Esc** | Bereich · hinzufügen oder entfernen · alle · keine |
| Fotothek | **P** | die Auswahl veröffentlichen |
| Fotothek | **L**, **Leertaste**, Doppelklick | Lupe; **← →** vorheriges oder nächstes Foto, **Esc** oder **Leertaste** schließt |
| Fotothek | **I** | Fotos importieren |
| Fotothek | **⌘Z** (Strg+Z) | die letzte Änderung rückgängig machen, die unten am Bildschirm angeboten wird |
| Fotothek | ein Vorschaubild auf ein anderes ziehen | ändert die Reihenfolge (ohne Filter) |
| Fotothek | ein Vorschaubild auf eine Serie in der Seitenleiste ziehen | ordnet es dieser Serie zu |
| Fotothek | Dateien irgendwo ablegen | importiert sie |
| Fotothek, ein Foto gewählt | **Details öffnen** (oben im Bereich) | öffnet die Seite des Fotos |
| Fotothek, auf dem Smartphone | ein Vorschaubild antippen, dann seinen Titel | wählt das Foto, dann öffnet es seine Seite |
| Fotothek → Inspektor | ein Feld verlassen oder Eingabe | speichert es |
| Liste | Menü **⋯** | bearbeiten, veröffentlichen oder zurückziehen, eine Position nach oben oder unten |
| Stapel vervollständigen | ein Feld verlassen | speichert es; Serie, Ort und Datum der Leiste gelten für die angekreuzten Fotos |
| Stapel vervollständigen, auf dem Smartphone | **Serie, Ort oder Datum für alle angekreuzten…** | öffnet die Felder der Leiste |
| Serien | Griff **⠿**, dann **↑ ↓ ← →** | verschiebt den Kontaktbogen um eine Position |
| Serien → neue Serie | **Eingabe** / **Esc** | erstellt / löscht die Eingabe |
| Öffentliche Website → Start-Diashow | **←** / **→** / **✕** | ordnet ein Foto der Diashow neu an oder entfernt es |
| Menüs ⋯, Fenster, Lupe, Palette | **Esc** | schließt sie |
| Auswahllisten, die etwas auslösen (Filter, Fotograf, Serie) | mit der Tastatur: **↑ ↓**, dann **Eingabe** (oder die Liste verlassen) | die Pfeile blättern, ohne etwas anzuwenden; Eingabe oder Verlassen wendet an (Filter: Eingabe oder **Filtern**) |

Tasten mit einem einzigen Buchstaben (**P**, **I**, **L**, **Leertaste**) wirken nur, wenn der Fokus im Kontaktbogen oder im rechten Bereich liegt (nach einem Klick auf ein Foto): nie aus der Seitenleiste oder von einem anderen Link aus, damit kein Tippfehler und kein Diktat etwas veröffentlicht.

Alles funktioniert mit der Tastatur: Für jedes Ziehen und Ablegen gibt es eine Entsprechung mit Schaltflächen oder Pfeiltasten. Auf dem Smartphone ersetzt die Tab-Leiste unten die Seitenleiste (**Menü** öffnet sie).

## Wenn der Browser das Speichern verweigert

Der Regler für die Vorschaubildgröße und die Meldungen der Verwaltung bleiben auf der aktuellen Seite nutzbar. Die gewählte Größe und Meldungen nach dem Neuladen werden nur gespeichert, wenn der Browser dies zulässt.

## Auf der öffentlichen Website

| Geste | Wirkung |
|---|---|
| **←** / **→** | vorheriges / nächstes Foto (Betrachter) |
| **Esc**, **Schließen**, Zurück-Taste des Browsers | zurück zur Serie (oder zur Galerie), an die verlassene Stelle (Betrachter) |
| waagerechtes Wischen | nächstes oder vorheriges Foto (Betrachter), Folie der Start-Diashow |
| Zwei-Finger-Geste (Pinch) | Zoom (Betrachter) |
| **Pause** / **Wiedergabe** | den Ablauf der Start-Diashow anhalten / wieder starten |
