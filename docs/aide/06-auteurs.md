# Auteurs

Une fiche par photographe.

| Champ | Rôle |
|---|---|
| **Nom** | affiché sur le site (filtre « deux regards », légendes, À propos) |
| **Adresse** | `/auteur/<adresse>` (fiches existantes seulement) |
| **Biographie** | affichée sur la page « À propos » ; version anglaise et allemande facultative, repliée dessous (vide : la biographie française) |
| **Lettre des cartes** | la lettre des cartes de rencontre (J-0142) ; vide : la première lettre de l'adresse. Une lettre par auteur (voir [Rencontres](rencontres)). |
| **Compte de connexion** | identifiant du compte qui se connecte à l'admin (voir ci-dessous) |

- **Enregistrer** : sous chaque fiche.
- **Ajouter un auteur** : formulaire « Nouvel auteur », en bas.
- **Supprimer** : ouvrez **Supprimer**, puis confirmez. C'est impossible tant que l'auteur a des photos.
- **Renommer** un auteur met à jour ses images si son nom figure dans le filigrane ou dans les métadonnées.

## Lier un compte à un auteur

Une fois le compte lié, ses imports lui sont attribués par défaut, et le tableau de bord indique « Ce compte est lié à l'auteur … ».

1. La personne se connecte : son tableau de bord affiche son identifiant de compte.
2. Copiez-le dans le champ **Compte de connexion** de sa fiche.
3. Cliquez sur **Enregistrer**.

Un compte ne peut être lié qu'à un seul auteur.
