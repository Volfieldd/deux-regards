# Réglages

| Champ | Où il apparaît |
|---|---|
| **Nom du site** | logo texte, titre des pages, variable `{site}` du filigrane. Vide : nom par défaut du serveur. |
| **Accroche** | titre de la section « regards » de l'accueil, titre de « À propos », description pour les moteurs de recherche |
| **Introduction** | texte sous l'accroche, à l'accueil |
| **À propos** | page « À propos ». Séparez les paragraphes par une ligne vide. |
| **Droits d'utilisation : texte** | page publique `/droits`. Vide : texte par défaut (droit d'auteur, auteurs nommés, reproduction interdite sans autorisation). |
| **Droits d'utilisation : contact** | adresse e-mail ou lien `https://`, affiché comme lien sur `/droits` |
| **Photos de l'ouverture** | le diaporama plein écran de l'accueil |

## Photos de l'ouverture

- **Sélection :** cochez jusqu'à **8 photos**, parmi les publiées. La vignette d'une photo choisie est entourée.
- **Ordre :** celui de la galerie (voir [Photos](photos#changer-lordre)).
- **Sans choix :** les 5 premières photos publiées.
- **Photo dépubliée ou supprimée :** elle sort de l'ouverture.
- **Adresse modifiée :** la photo y reste.

Cliquez sur **Enregistrer les réglages**.
