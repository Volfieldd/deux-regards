# Gestes et raccourcis

## Dans l'admin

| Où | Geste | Effet |
|---|---|---|
| Photos → zone d'import | glisser des fichiers depuis l'ordinateur | les ajoute au lot |
| Photos → zone d'import | clic, ou Entrée quand elle a le focus | ouvre le choix de fichiers |
| Photos → liste | glisser une ligne sur une autre | la déplace : moitié haute = avant, moitié basse = après |
| Photos → liste | **↑** / **↓** | monte ou descend d'une place (clavier, sans souris) |
| Photos → liste | **Publier** / **Dépublier** | change le statut sans quitter la liste |
| Toute fiche | **Supprimer…** puis **Supprimer définitivement** | suppression en deux gestes, jamais par erreur |
| Filigrane & EXIF | **Aperçu sans enregistrer** | rendu dans un nouvel onglet, rien n'est enregistré |
| Apparence | **Aperçu** sous un thème | site avec ce thème, pour vous seul |
| Partout | **Tab** / **Maj + Tab** | passer d'un élément à l'autre (le focus est entouré) |
| Partout | **Entrée** sur un bouton | l'activer |

Tout fonctionne au clavier : chaque glisser-déposer a son équivalent en boutons.

## Sur le site public

| Geste | Effet |
|---|---|
| **←** / **→** | photo précédente / suivante (visionneuse) |
| **Échap** | retour à la galerie |
| glissé horizontal | photo suivante ou précédente (visionneuse), diapositive de l'ouverture |
| pincement | zoom (visionneuse) |
| **Pause** | arrêter le défilement de l'ouverture |
