# Gestures and shortcuts

## In the admin

| Where | Gesture | Effect |
|---|---|---|
| Everywhere | **⌘K** (Ctrl+K) | palette: find a photo, a series, a page, or run an action |
| Everywhere | **Tab** on arrival | shows **Skip to content**: Enter skips the sidebar |
| Everywhere | **sun / moon** button | light or dark mode |
| Photo library | **click** on a thumbnail | selects it alone: the inspector shows it |
| Photo library | **Shift + click** · **⌘ + click** · **⌘A** · **Esc** | range · add or remove · all · none |
| Photo library | **P** | publish the selection |
| Photo library | **L**, **Space**, double click | loupe; **← →** previous or next photo, **Esc** or **Space** closes |
| Photo library | **I** | import photos |
| Photo library | **⌘Z** (Ctrl+Z) | undo the last change offered at the bottom of the screen |
| Photo library | drag a thumbnail onto another | changes the order (no filter) |
| Photo library | drag a thumbnail onto a series in the sidebar | files it in that series |
| Photo library | drop files anywhere | imports them |
| Photo library, one photo chosen | **Open details** (top of the panel) | opens the photo’s page |
| Photo library, on a phone | tap a thumbnail, then its title | chooses the photo, then opens its page |
| Photo library → inspector | leave a field, or Enter | saves it |
| List | **⋯** menu | edit, publish or unpublish, move up or down one place |
| Complete the batch | leave a field | saves it; the bar’s series, place and date apply to the ticked photos |
| Complete the batch, on a phone | **Series, place or date for all ticked…** | opens the bar’s fields |
| Series | **⠿** handle then **↑ ↓ ← →** | moves the contact sheet by one place |
| Series → new series | **Enter** / **Esc** | creates / clears the entry |
| Public site → opening slideshow | **←** / **→** / **✕** | reorders or removes a photo from the slideshow |
| ⋯ menus, windows, loupe, palette | **Esc** | closes them |

Everything works from the keyboard: every drag and drop has an equivalent in buttons or arrow keys. On a phone, the tab bar at the bottom replaces the sidebar (**Menu** opens it).

## On the public site

| Gesture | Effect |
|---|---|
| **←** / **→** | previous / next photo (viewer) |
| **Esc**, **Close**, the browser’s Back button | back to the series (or the gallery), where you left off (viewer) |
| horizontal swipe | next or previous photo (viewer), slide of the opening slideshow |
| pinch | zoom (viewer) |
| **Pause** / **Play** | stop / restart the opening slideshow |
